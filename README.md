# 🔢 Proyecto: Contador de Ejemplo

¡Bienvenido al repositorio! Este proyecto es una herramienta educativa diseñada para entender los fundamentos del desarrollo web. Aquí veremos cómo interactúan el **esqueleto**, el **estilo** y el **cerebro** de una aplicación web.

## 🚀 ¿Qué vamos a aprender?

Este proyecto divide el aprendizaje en tres grandes pilares:

### 1. Estructura (HTML)
El archivo `index.html` contiene la estructura de nuestra página.
- **Etiquetas:** Aprendemos a usar `<div>`, `<h1>`, `<span>` y `<button>`.
- **IDs y Clases:** - Usamos `id` (identificador único) para que JavaScript sepa exactamente qué número cambiar.
  - Usamos `class` (clases) para dar el mismo estilo a varios botones a la vez.

### 2. Diseño (CSS)
En el archivo `style.css` definimos la apariencia.
- **Propiedades y Valores:** Cómo cambiar el `color`, el `font-size` (tamaño de letra) y el `background` (fondo).
- **Alineación:** Veremos cómo centrar elementos usando `flexbox` para que se vean bien en cualquier pantalla.
- **Selectores:** Cómo "apuntar" a una etiqueta, a una clase o a un ID para darle estilo.

### 3. Lógica y Funcionalidad (JavaScript)
El archivo `app.js` (o `script.js`) es donde ocurre la magia.
- **Variables:** Usamos `let` para crear un espacio en la memoria que guarde el número actual del contador.
- **DOM (Document Object Model):** Aprendemos a usar `document.getElementById` para "atrapar" elementos del HTML desde nuestro código.
- **Event Listener (Escuchadores de eventos):** El programa se queda "esperando" a que el usuario haga `click` en un botón.
- **Funciones:** Bloques de código que se ejecutan para realizar la suma, la resta o el reinicio.

---

## 🛠️ Cómo usar este ejemplo en clase

1. **Exploración:** Abre el archivo `index.html` en tu navegador.
2. **Modificación de Estilo:** Intenta cambiar el color del número en el CSS.
3. **Desafío de Lógica:** Ve al código JavaScript e intenta que el botón de "Sumar" ahora sume de 2 en 2 en lugar de 1 en 1.
4. **Reseteo:** Asegúrate de entender qué hace la función que pone el contador en 0.
